# Markdown 一键导出

面向 **思源 v3.8.10、Docker 部署、桌面浏览器** 的插件。文档树右键单篇文章，选择「导出 Markdown」，自动下载包含正文和附件的 ZIP。插件代码也允许桌面客户端加载，但当前主要验收目标是 Docker 浏览器。

## 安装

1. 下载本仓库源码，按下方「本地开发」步骤构建，解压生成的 `dist/siyuan-2md-0.1.0-manual.zip`，将其中的 `siyuan-2md` 文件夹复制到思源工作空间的 `data/plugins/`。
2. 确认安装路径为 **思源工作空间的 `data/plugins/siyuan-2md/`**。目录名不能带版本号；`plugin.json` 和 `index.js` 必须直接位于该目录，不要再嵌套一层文件夹。
3. Docker 环境请在工作空间的宿主机挂载目录中操作。例如容器工作空间为 `/siyuan/workspace` 时，容器内目标为 `/siyuan/workspace/data/plugins/siyuan-2md/`，宿主机路径以你的 volume 映射为准。
4. 刷新思源浏览器页面，在「设置 → 集市 → 已下载 → 插件」中启用「Markdown 一键导出」。若当前界面提供插件安装入口，也可按该入口的要求使用 ZIP。
5. 在左侧文档树右键一篇文章，点击「导出 Markdown」。首次使用可先用包含一张图片和一个 PDF 的测试文章验证。

无需 npm、额外容器、Pandoc、API Token 或外部 CDN。浏览器通过当前思源登录会话调用同源内核接口。仅在单篇文档菜单显示；笔记本和多选菜单不显示。

## 导出结果

```text
文章标题.zip
  文章标题.md
  assets/
  导出说明.txt（有异常或已识别的转换限制时）
```

- 只导出当前文章，显式排除子文档和关联整篇文章。标题自动处理 Windows 非法字符与保留名称。
- 思源内部图片、PDF、音视频等本地附件一起打包，改写为相对地址。保留 PDF 页码等链接片段。
- 外链图片由 Docker 内核代为下载，单张等待 30 秒、最大 20 MiB，并发 3 个；相同地址只下载一次。20 MiB 在代理返回后校验，思源内核还有自身的响应大小上限，并非网络层精确限流。
- 外链图片若失效、超时、超限或遇到鉴权/防盗链，保留原链接并报告，不中断正文导出。不向外链站点转发思源登录凭证。
- 普通网页链接和外链音视频不下载；`data:` 内嵌图片保留。HTML `srcset` 会提示未展开。
- 块引用采用官方「脚注 + 锚点」模式，嵌入块使用原始正文模式。公式、代码和 Mermaid 保留源码，显示效果取决于阅读器。
- 不写原文、全局导出设置或笔记中的图片。官方导出会产生思源管理的临时导出文件。
- 导出面板显示阶段、资源数量和压缩进度，支持取消。完成后自动触发浏览器下载，面板在 1 秒后自动关闭，不显示重新下载按钮；失败时保留提示。下载目录与保存对话框由浏览器设置决定。

## 边界

取消会停止插件后续处理与下载，终止浏览器请求；已经开始的思源内核导出或代理请求可能仍执行到完成或超时。为避免官方同名临时文件冲突，插件同一页面一次处理一篇文章。

ZIP 在浏览器内存中读取、压缩。本地附件不设置 20 MiB 限制，大视频或超大文档会占用较多内存。跨页面同时导出同名文档时仍可能受到内核临时路径机制影响。

数据库、挂件、动态查询、内嵌网页等不保证完整转换。插件对可识别的残留特殊语法提供说明，无法证明所有内容均无损。依赖其他文档的思源链接不会自动打包对应整篇文档。外链图片是否可访问取决于 Docker 网络与远端权限。

反向代理子路径按浏览器 `/前缀/stage/...` 推导；代理须同时转发该前缀下的 `api/`、`export/` 和 `assets/`。服务端导出错误或意外多文档结果会停止下载并显示原因。

## 本地开发

Node.js 20+，依赖已随源码固定提供，无需安装：

```sh
node --test test/*.test.cjs
node scripts/build.cjs
```

输出：`dist/siyuan-2md/`（可直接复制安装）、`dist/siyuan-2md-0.1.0.zip`（插件文件位于 ZIP 根目录）和 `dist/siyuan-2md-0.1.0-manual.zip`（包含正确目录名的手动安装包）。

- `src/index.cjs`：菜单、进度、取消和浏览器下载。
- `src/exporter.cjs`：内核接口、ZIP、资源处理。
- `src/markdown.cjs`：保留源码格式的资源定位与改写。
- `vendor/`：JSZip 3.10.1、Marked 17.0.5 及各自许可证。
- `docs/verification.md`：接口依据、测试和真实环境验收清单。
